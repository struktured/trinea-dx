# script/: English script

| Path | What |
|---|---|
| `src/*.txt` | **Source of truth.** One `MESSAGE_ID English text` per line, block by block. Lines starting with `#` are comments. |
| `en/*.json` | Generated by `tools/py/merge_en.py` and read by the inserter. English only: message IDs, block/kind/structure, and the `en` text. |
| `en_system_layout.json` | English strings and cell layout for the pre-rendered system text (character select, shop, money label), used by `tools/py/sysgfx.py`. |
| `glossary.md` | Names and terms, with the reasoning for each choice. |
| `TRANSLATION_NOTES.md` | Translator's notes, open questions and corrections to the original. |

No Japanese script is stored here. `tools/py/dump_script.py` writes the original script to `build/jp/` from your own
ROM when you need it: merge_en.py uses it for deduplication and validation, and it writes a side-by-side
proofreading file to `build/proofread_jp_en.txt`.

## Tags

The English text uses the game's control codes as bracket tokens:

| Tag | Byte | Meaning |
|---|---|---|
| `[page]` | 82 | clear the text box / new page |
| `[wait]` | 80 | wait for a button press |
| `[br]` | 83 | hard line break |
| `[hl]` | 8A | toggle highlight (speaker names) |
| `[88]`, `[81]`, `[XX]` | XX | other original control bytes, passed through |
| `[END]` / `[ENDK]` | FE / FF | end of message (FF keeps the box open; the next message continues on the same line) |

## Conventions

- Speaker tag: `[hl]Name[hl]: text`, inline. The inserter word-wraps to the 192 px box with the variable-width font
  and adds page breaks after 3 lines. Manual `[br]` is only used in the opening/ending cutscenes (which do not wrap),
  in the profile stat lines and in the version string.
- `[wait][page]` is kept wherever the original has a page break. merge_en.py warns when a page is over about 95 characters.
- System prompts use `<...>`. Text is ASCII (a Unicode `…`, if used, maps to the font's ellipsis glyph).
- `SYS_*` lines in `src/PROFILE_SYSTEM.txt` are an English-only list kept for reference. The shipped build renders
  system text from `en_system_layout.json`.
